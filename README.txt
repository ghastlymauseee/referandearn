# Referandearn starter website

## What is included
- `index.html`: responsive referral directory with search and category filters.
- `privacy.html`: basic privacy-policy starter page.
- `disclaimer.html`: referral/affiliate disclaimer starter page.

## Before launch
1. Open `index.html` in a browser to preview.
2. Edit the `offers` array in the script near the bottom of `index.html`.
3. For each offer, update `url` with your actual referral URL, `offer` with accurate details, `desc` with original helpful information, and `status` with a truthful status.
4. Remove any app or offer you cannot verify. Check each programme's rules about sharing links publicly.
5. Replace `YOUR_EMAIL@example.com` with a public contact email.
6. Review the privacy and disclaimer pages for your real setup.
7. Do not promise rewards that are not guaranteed. Update offer details and expiry dates when they change.

## Free public launch (GitHub Pages)
1. Create/sign in to a GitHub account.
2. Create a **public** repository named `referandearn` (or another name).
3. Upload `index.html`, `privacy.html`, and `disclaimer.html` to the repository root and commit.
4. In repository Settings -> Pages, choose deployment from the `main` branch and `/ (root)`, then save.
5. Wait for the published URL shown in Settings -> Pages. It will typically look like `https://YOUR-USERNAME.github.io/referandearn/`.
6. Open the URL on desktop and mobile to test all links and search.
7. A custom domain is optional and normally costs money; it is not included in this free starter.

GitHub Pages is free for public repositories, but it serves static files only. This starter therefore has no admin dashboard or database; editing offers means updating the `offers` list in `index.html` and uploading the revised file.

## SEO next steps
- Add original, useful content to each app's own page, including eligibility, exclusions, expiry and last checked date.
- A single-page demo is not enough to target every `app name + referral code` query effectively. Add indexable individual app pages as the directory grows.
- Connect Google Search Console after publishing and submit a sitemap once you create one.
- Never copy misleading claims or pretend offers are verified if they are not.
